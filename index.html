📥 Import – Aggregate

Importiere eine Aggregat-Konfiguration aus einer JSON-Datei. Die Datei wird z.B. mit Google Drive oder per USB-Stick übertragen. Bestehende Aggregate mit gleicher ID werden überschrieben.

📥 Import – Protokolle

Importiere ein gespeichertes Wartungsprotokoll aus einer JSON-Datei. Nützlich um Protokolle von einem Gerät auf ein anderes zu übertragen.

📤 Export – Alle Aggregate

Exportiert alle konfigurierten Aggregate als eine JSON-Datei. Ideal als Backup oder zum Übertragen auf ein anderes Gerät.

📤 Export – Alle Protokolle

Exportiert alle ausgefüllten Wartungsprotokolle als eine JSON-Datei. Diese Datei kann dann in der Firma für die Protokoll-Erstellung genutzt werden.

ℹ️ Hinweise

Offline-Betrieb: Die App speichert alle Daten lokal im Browser (IndexedDB). Es ist keine Internetverbindung nötig.

Datei-Übertragung: JSON-Dateien können über Google Drive, OneDrive, E-Mail oder USB-Stick übertragen werden.

Browser-Daten: Wenn du den Browser-Cache leerst oder „Alle Daten löschen" verwendest, gehen alle Daten verloren. Exportiere regelmäßig als Backup!

Installation: Die App kann über das Browser-Menü „Zum Startbildschirm hinzufügen" / „App installieren" installiert werden.
